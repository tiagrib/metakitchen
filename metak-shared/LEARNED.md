# Learned

Discoveries worth carrying into future work. One `##` section per learning.

Each entry has:

- **Discovery** — dated, with the task or context where it surfaced, and the root cause.
- **Implication** — what to do differently next time, concretely.
- **Detection tip** — how to recognize this failure from its symptom (optional but high-value; symptoms rarely resemble causes).
- **Reference** — `file:line`, commit SHA, or contract that shows the canonical fix.

Write the entry so someone who was not there can act on it. "Be careful with X" is not an entry; "X silently drops Y, detect it by Z, fix pattern is W" is.
